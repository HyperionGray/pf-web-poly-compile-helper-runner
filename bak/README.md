# Archive
This directory keeps tracked historical material that is useful for reference but should not stay in the active top-level user surface.
## Layout
- `bak/task-audit/` — archived `pf` task-audit runs and their logs/results
- `bak/reports/` — one-off generated report artifacts that were previously tracked at the repo root
- `bak/installers/` — deprecated or superseded installer material kept for reference
## Guidance
New generated artifacts should not be added at the repo root when they are purely historical output.
If an artifact is still useful, archive it here with a short note or a stable filename that explains what it is.

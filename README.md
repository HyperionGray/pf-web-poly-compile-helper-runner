# pf-web-poly-compile-helper-runner

This repository contains **pf-runner** plus supporting scripts, containers, and `Pfyfile.*.pf` task definitions for polyglot compilation and related workflows.

## Quick start

- Install (auto-detects best mode): `./install.sh`
- Read the task DSL + examples: `docs/QUICKSTART.md`
- Run tests: `bash run_test.sh` or `bash run_tests.sh`

Project documentation lives in `docs/`.
